# Test standards

- Go tests live beside the code as `*_test.go`. Prefer table-driven tests and existing fixtures.
- A test writes files with `os.WriteFile(..., 0o600)`. gosec reports a broader mode as G306. When the test needs one, for example for a script that it runs, give the reason in `//nolint:gosec // G306: <reason>`.
- A row that shows the bug or the new behavior must fail against the code before the change. A row that expects no output can pass for the wrong reason, so the table also needs a case that does produce output.
- If a helper returns a value that the caller writes as a durable decision, for example a cooldown stamp or a delete, test the caller expression that writes it. A test of the helper alone does not cover that expression.
- To test a qBittorrent timeout or cancellation path, put a `&Client{Client: qbt.NewClient(...)}` into `pool.clients` that points at an `httptest` server whose handler waits on `<-r.Context().Done()`. `pool_test.go` has examples. Do not use `NewClientWithTimeout`, because it logs in at once on a detached `context.Background()`. To find a cancellation, use `isContextStopped`, not `errors.Is`. The go-qbittorrent retry wrapper flattens the error, so `errors.Is` does not find `context.Canceled`.
- A change to a log level, a message text, or a constant needs no test. The reviewer reads the change in the diff. The exception is the log budget test that `docs/standards/logging.md` asks for.
- Do not add a test that does only one of these things:
  - It repeats a type or a constant.
  - It checks that a mock got a call, and checks nothing about the result.
  - It checks that a function returns the error from a dependency without a change.
  - It adds a table row that runs the same branch as another row. The match corpus in `internal/services/crossseed/match_corpus_test.go` is an exception, because it grows freely.
  - It checks a CSS class string or static markup in a frontend test.
- To wait for a goroutine, use a channel. To test code that waits on a timer, run the test in `synctest.Test`, where `time.Sleep` moves a fake clock. The lint ratchet reports a real `time.Sleep` as `testsleep`. "Sleeps in Tests" in `docs/linting.md` describes the check. A real rate limiter or ticker waits like a sleep, so give the test an unlimited one, unless the limit is what it tests. The Windows clock moves in steps of up to 16 ms, so a test that needs a later time sets that time, or outside `synctest.Test` waits for the clock to move as `nextClockStep` in `internal/services/transfer/purge_test.go` does.
- A test that touches a database, also through a store or a service, does not run in `synctest.Test`. On the fake clock, the statement cache closes its statements, and the test fails at random with "statement is closed".
- If a test comes from a bug fix, put `// regression: #N` on the line above it. N is the number of the fix PR or the issue. The Regression marker check fails a PR whose title starts with `fix` when a test file gets a new test function, subtest, `it`/`test` call, or row of a Go table of an anonymous struct, and no marker. ADR 0086 lists what it misses. It needs one marker in each such file, not one for each test. It reads commits only, so commit, then run it before you push with `make check-regression-marker TITLE="<PR title>" NUMBER=<PR number>`. Before you remove a test with this tag, show that another test catches the same bug.
- A test that needs two real paths on one volume, for example a hardlink source and its destination, makes both under one `t.TempDir()`. An invented path such as `/media` can be on another volume than the temporary folder, and the link then fails on the Windows runner.
- Call `t.TempDir()` before you start a server or a pool that opens files in it. Cleanup runs in reverse order, so the server closes its files before the test removes the folder. Windows does not remove a folder that holds an open file.
- Skip a test for a missing capability only on the error that names it, for example Windows error 1314 when the user cannot create a symlink. A skip on `runtime.GOOS` alone also skips the test on a host that has the capability.
