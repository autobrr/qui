## Breaking changes
- **New release signing key.** If you skip this release and later update an older version with the in-app updater, the update fails with a signature error. Download the new release by hand one time, and the in-app updater then works again. Docker images are not affected.

## Highlights
- **Cross-seed routes.** Pick a Cross-seed instance on the Hardlink / Reflink Mode card, and qui adds the cross-seeds there and shows where each one went. The Cross-seed instance needs qBittorrent 5.0 or later.
- **Full-screen torrent details on a phone.** The details view fills the screen and has a section bar at the bottom. The Peers tab also shows an icon for each peer client.
- **Smoother torrent table.** A steady scroll in the desktop table no longer stops at every 100 rows.
- **Safer orphan scan.** Orphan scan keeps the files and empty folders that a torrent or another instance reaches through a symlink or a bind mount.
- **Cross-seed and Dir Scan fixes.** qui no longer uses a source that qBittorrent moves or checks, and it adds matches whose download name has no group. A Full Dir Scan reads the directory one time, so a scan over SSH no longer takes hours.
- **Fixes and polish.** Arrow keys work in path autocomplete, dialogs keep a side margin on phones, the workflow preview shows translated states, the automation editor lists actions in run order, paused exports with checking on pass verification, the client proxy works with apps that send a Referer, cross-seed metrics show on `/metrics`, indexer health works on SQLite, season pack runs show Applied first, and native Torznab searches send the correct type.
