This is a big one.

## Breaking changes
- **Browser-only routes refuse API keys.** Scripts using an API key now get `403 API key not allowed; use the web UI` when managing API keys, updating or restarting qui, setting SSH credentials, changing the password, managing the license, or creating, editing, and deleting external programs. Run those actions in the web UI instead.
- **Orphan scan runs list replaces `scanPaths` with `scanPathCount`.** `GET /api/instances/{id}/orphan-scan/runs` no longer returns `scanPaths` for each run. Update scripts to read `scanPaths` from `GET /api/instances/{id}/orphan-scan/runs/{runID}` instead.
- **Orphan scan lists hardlinks of torrent files again.** Orphan scan no longer skips hardlinks of seeding torrents in other locations, as before v1.34.0. If a scan root holds hardlinks you want to keep, such as a media library, add an ignore path for that folder.
- **Automation workflows require one condition across all enabled actions.** API clients and JSON imports saving a workflow with different conditions per action now get a `400` error (`All actions in a workflow must use the same condition. Make one workflow for each condition.`). Split those rules into one workflow per condition; already-saved workflows keep running until their actions or conditions change.

## Highlights
- **Statistics page and redesigned Dashboard.** Track upload, download, top torrents, library growth, and deleted torrents. The new Dashboard pairs live and 24-hour transfer with **Unique size**, so cross-seeds count once.

  ![Statistics page](https://github.com/user-attachments/assets/509d236b-19f7-41cc-8046-67ac5a3cd68e)

  ![Dashboard](https://github.com/user-attachments/assets/2caff019-94b8-40aa-bb9e-236c4cb7309f)

- **Lower memory use.** First-sync peak memory at 50,000 torrents drops from 807 MB to 235 MB. Cutting the SQLite page cache from 64 MB to 2 MB per connection returns about 40 MB on a typical install and up to about 1 GB on a large one.

- **Transfer and Share torrents (Beta).** Move a torrent, its cross-seeds, and files to another instance with copy verification, manually or via **Transfer to Instance** rules. You can also share a torrent's files outside qui.

  ![Transfer to Instance](https://github.com/user-attachments/assets/35775ea0-3edd-42b9-a5d9-9473f04ccf40)

- **Remote SSH file access and scoped API keys.** Set up SSH with host-key pinning in instance preferences for remote orphan scan, cross-seed link mode, and free-space checks. Scope API keys by area permission and instance in **API Keys** settings.

  ![SSH tab](https://github.com/user-attachments/assets/faee5bc1-de12-4240-9b02-ae35d5f1ac63)

- **Group copies, command palette, and themes.** Collapse cross-seeds into one row with **Group copies** and jump anywhere with **Cmd/Ctrl+K**. Try the free **Meridian** theme; licensed users also get a custom theme editor and 41 built-in community themes.

  ![Group copies](https://github.com/user-attachments/assets/a629d995-05c3-4490-9ac4-b3a89e259851)

  ![Command palette](https://github.com/user-attachments/assets/93c3f089-76a5-4c3c-a200-631ac6a81d25)

  ![Themes](https://github.com/user-attachments/assets/2b00b129-1977-466e-b124-4da11171244a)

- **Fixes and polish.** Per-screen **Display profiles**, **Instance icons** (56 stock icons, letters, and colors), scheduled Library Scan and RED/OPS status, **Allowance on a path** free space, safer automation guards, System notices, single-user OIDC limits, new Add Torrent dialog, and mobile fixes.

  ![Instance icons](https://github.com/user-attachments/assets/5eeb0a32-4ace-44ac-924d-79064b238e69)
