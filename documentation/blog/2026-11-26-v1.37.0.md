## Highlights
- **Redesigned Search and bulk selection.** Search fits every screen in one table with filter buttons and a bar to add multiple results at once. Transfers and Tracker customizations get the same selection bar.

  ![qui Search page listing indexer results with filter buttons, four rows selected, and a "4 selected" bar with Add](https://github.com/user-attachments/assets/15f154b5-1691-4609-9362-f989424bac4c)

- **Faster, more reliable Transfers.** Up to 3 Transfers per source run at once (2.3 to 2.5x faster on small queues), and large BitTorrent Transfers or rechecks no longer stall or fail. Helper torrents stay out of Copy groups, notifications, and automations.

- **Better cross-seed and Dir Scan.** Season pack and RED/OPS searches now check trackers where you only seed single episodes or tracks, and TV searches retry with the year. Dir Scan adds per-indexer retries and shared paths with `instanceId`.

- **API key templates and security.** One-click templates set up keys for autobrr, dashbrr, Homepage, the arrs, and qui-extension, while keys without write access no longer get passkeys, RSS links, or tokens. Content downloads block qui's config and database, and proxy, email, and Postgres passwords stay hidden.

  ![Create API Key dialog with one-click templates; qui-extension (cross-seed) picked and its permissions ticked](https://github.com/user-attachments/assets/c62629d4-0d00-489c-b92c-02a703e6f3e4)

- **Sidebar, Statistics, and themes.** Hide the desktop sidebar completely with **Hide sidebar**, and get matching status colors in all 50 themes. Statistics restores tracker logos, adds a **Seeded** column, and groups hourly charts by day.

- **Fixes and polish.** CIFS/SMB hardlink counts, batched uploads past 995 `.torrent` files, SSH on Ubuntu 25.10+ and non-POSIX shells, quieter logs, slow-disk startup, torrent tooltips, Dashboard disk warnings, and phone and iOS polish.
