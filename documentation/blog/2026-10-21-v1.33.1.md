## Highlights
- **Go 1.27.3 security fixes.** qui builds with Go 1.27.3, which stops trusting a small set of eMudhra intermediate certificates (CVE-2026-111943). The build also includes the Go security fixes for `crypto/tls`, `net/http`, `html/template`, `net/textproto`, and `os`.
- **Fixes and polish.** Docker image tags publish only after the release build succeeds, the release builds fetch the premium themes again, and the Discord card for a release page shows one Breaking notice.
