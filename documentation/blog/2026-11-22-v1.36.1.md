## Security fix
- **API keys can no longer change the log file path.** Previously, someone else holding one of your API keys, such as a leaked key, could change that path, and through it read and change files of the OS user running qui. If you have one or more API keys, upgrade and check the path in Settings → Logs, where only a signed-in browser can change it now. See [GHSA-9c3v-4vv2-9wrf](https://github.com/autobrr/qui/security/advisories/GHSA-9c3v-4vv2-9wrf).
- **New log file paths must end in .log.** A new log file path set in Settings must end in `.log` or be empty. Existing paths stay as they are.
