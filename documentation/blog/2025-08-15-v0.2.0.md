# ⚠️ Breaking Changes

## Database Schema ([#38](https://github.com/autobrr/qui/pull/38))
- Instances now use single `url` field instead of `host`/`port`
- **Required**: Delete existing database and recreate
  - Backup your license key or recover from Polar portal

## Environment Variables ([#27](https://github.com/autobrr/qui/pull/27))
- `QUI__DATABASE_PATH` renamed to `QUI__DATA_DIR`
- `--config` flag renamed to `--config-dir`

## CLI Commands ([#60](https://github.com/autobrr/qui/pull/60))
- Server must be started with `qui serve` instead of `qui`
