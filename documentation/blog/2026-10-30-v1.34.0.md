## Breaking changes
- **The Dir Scan status endpoint returns a list.** `GET /api/dir-scan/directories/{id}/status` now returns `{"runs": [...]}`, so a script that reads the old shape must read `runs`. The webhook endpoint no longer returns `409` for a scan in progress.
- **Relative Move paths are rejected.** qui skips an enabled rule whose Move path is relative after the template renders, and it refuses to save that rule. Make the Move path absolute.
- **Invalid Move path templates are rejected.** qui refuses to save an enabled rule whose Move path is an invalid template. Fix the template.
- **On Windows, Program Path must be an executable.** For a Python, PowerShell, or other script, select the interpreter as **Program Path** and pass the script path as the first argument. For a shortcut, select its target executable.
- **On Windows, batch and terminal arguments are literal.** `%NAME%` and operators such as `&` in the argument template of a `.bat`, `.cmd`, or terminal program no longer take effect. If the script needs an environment variable, read it in the script.

## Highlights
- **Much lighter on qBittorrent 5.2.** Tracker health now reads the 5.2 announce flags and no longer fetches the whole library every 60 s, so qui and qBittorrent use 7 to 10 times less CPU when idle.
- **A live details panel.** The General, Trackers, and Content tabs update while they are open, and General shows live piece counts on qBittorrent 5.2.
- **Safer deletes.** Delete rules skip a torrent while qBittorrent checks it, and the Delete dialog finds the cross-seeds of every selected torrent, also on other local instances.
- **Orphan scan keeps torrent data.** It no longer deletes files that a torrent reaches through a symlink, a bind mount, or a hardlink, or the folders that qBittorrent monitors or downloads into.
- **Run a workflow now.** Run one saved workflow from its row menu or its dialog, also when the workflow is disabled.
- **Fixes and polish.** Dir Scan webhooks search during a full scan, `qui migrate utorrent` with `--replace-path`, better cross-seed matching for season folders and HYBRID, category edits keep the download path, no stale progress after a failed sync, and UI polish.
