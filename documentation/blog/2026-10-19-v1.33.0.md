## Breaking changes
- **Start paused uses the qBittorrent preference.** Make sure that the start paused preference in qBittorrent has the value that you want for new torrents.
- **The preferences API returns a list of fields.** `GET /api/instances/{instanceID}/preferences` returns fields, not the preferences object. `PATCH` returns 400 for an unknown, read-only, or hidden key, or for a value of the wrong type. If a script reads or writes preferences through the qui API, update the script.
- **Torrent list and stream frames no longer carry `preferences`.** If a client reads this field from `GET /api/instances/{instanceID}/torrents` or from the stream, read `GET /api/instances/{instanceID}/preferences` instead.

## Highlights
- **Preferences dialog in the qBittorrent layout.** The instance settings dialog uses the tabs of the qBittorrent WebUI. The RSS settings are now in the RSS tab.
- **Many more qBittorrent settings.** You can now change the proxy, I2P, WebUI, email notification, network binding, Downloads, and Advanced settings in qui. Path fields suggest folders on qBittorrent 5.0+.
- **Leftover folders are cleaned up.** After a delete with files or a move, qui removes the empty folders that the torrent leaves behind. To keep a folder, add it to the orphan scan ignore paths.
- **More cross-seed matches.** Fansub groups with hyphens or bracket tags now match, and so do `HDR` against `HDR10`, Season numeral packs, and absolute episodes with a leading zero. A cross-seed with an extra nfo or subtitles now shows as Content.
- **Torrent views recover from a stalled stream.** If a view gets no data for two minutes, it loads from the server until the live updates return.
- **Fixes and polish.** Copy Full Path for renamed torrents, Tracker down instead of Unregistered for an `(unknown HTTP error)`, a Clear filters button on mobile, PWA reloads, tracker icons only from public addresses, and stricter automation rule import.
