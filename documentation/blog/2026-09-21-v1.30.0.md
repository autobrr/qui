### Breaking
Enter your Dodo key again if you still had a Polar license. This release removes the legacy Polar license support.
### Highlights
- **Hardlink mode no longer risks your source files.** When a hardlinked file failed its recheck, auto-resume could still start the torrent. qBittorrent then wrote the missing pieces into the hardlink and changed the file that your original torrent seeds. qui now leaves such torrents paused and names the file in the log and in a new "Resume" row of the season pack history.
- **Stricter login and sessions.** qui limits password login to five failures per minute, and a password change signs out every session. The new `sessionCookieSecure` option marks the session cookie Secure for HTTPS setups. Write requests that use the session cookie now need an `X-Requested-With` header. The web UI sends it, but a script that reuses a browser cookie must use an API key instead. The new optional `allowedHosts` setting blocks DNS rebinding and is off by default.
- **Less database churn, most of all on Postgres.** File cache refreshes now write only the rows that changed. One homelab measured 16% of its cluster WAL on unchanged rows, now zero, and SQLite runs the same refresh 3-4x faster. RSS polls no longer rewrite unchanged feed items. Concurrent file fetches no longer fail with "deadlock detected". Backup archive filenames stay the same across runs for torrents with several trackers.
- **New automation condition: Season pack status.** Each torrent is a pack, an episode that a pack covers, or an episode with no pack. An any-instance variant looks across all your instances. Use it to tag season packs or to clean up episodes that a pack already covers. Matching is strict, so a 720p pack never counts as cover for a 1080p episode. Dry runs now report the same torrents as the impact preview instead of stopping at the delete cooldown gates.
- **Gazelle cross-seed finds older uploads.** RED and OPS hash lookups also try the legacy PTH and APL source flags. Uploads from before the renames now match by infohash instead of a filename search. A failed lookup (tracker down, rate limited) no longer starts the torrent's cooldown.
- **Catalan is language number eleven.** The Catalan translator for the *arr apps contributed it. Czech now renders counts 2-4 instead of English, and several plural strings are fixed across locales.
- **Fixes and polish.** getqui.com now embeds a live demo of the real frontend with 10,000 synthetic torrents and no login. The Create Torrent source picker lists files and works with Windows paths. Downloads from the Content tab show the real size and progress and can resume. "Export all" under a parent category includes its subcategories. Select-all in cross-seed mode follows the visible rows. The tab icon no longer stays blank in Firefox background tabs. `--config-dir` with no config.toml writes a default instead of a crash.

Thanks to **ColinHebert**, **nitrobass24**, **thejdubb02**, **schwarz**, and **Kisnov** for contributing to this release.
