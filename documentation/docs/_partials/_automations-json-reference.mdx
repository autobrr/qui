## JSON reference

This section lists every key of a rule as JSON, the condition fields and their operators. Legacy keys that qui still accepts in older rules are left out.

### Rule

| Key | Type | Values | Description |
| --- | --- | --- | --- |
| `name` | string |  | Rule name. Required. |
| `trackerPattern` | string |  | Tracker domains that the rule applies to, separated by commas. `*` matches all trackers. `tracker.example.com` matches one domain, `*.example.com` its subdomains, and `.example.com` the domain and its subdomains. A leading `!` excludes a domain. |
| `enabled` | boolean |  | Whether the rule runs. Import always sets it to `false`. Edit as JSON keeps the current value. |
| `dryRun` | boolean |  | When `true`, the rule logs what it would do and changes nothing. Default `false`. |
| `notify` | boolean |  | When `true`, qui sends a notification when the rule acts. Default `true`. |
| `sortOrder` | integer |  | Position of the rule in the list. Import puts the rule at the end. Edit as JSON keeps the current value. |
| `intervalSeconds` | integer |  | How often the rule runs, in seconds. At least `60`. Default `900` (15 minutes). |
| `conditions` | object |  | The actions of the rule, each with its condition. Required. See `conditions`. |
| `freeSpaceSource` | object |  | Where the `FREE_SPACE` condition field reads free space. Default: the free space that qBittorrent reports. See `freeSpaceSource`. |
| `sortingConfig` | object |  | The order in which the rule processes torrents. Default: oldest first. See `sortingConfig`. |

### `conditions`

| Key | Type | Values | Description |
| --- | --- | --- | --- |
| `schemaVersion` | string |  | Must be `1`. |
| `grouping` | object |  | Group definitions for group-aware actions and conditions. See `conditions.grouping`. |
| `speedLimits` | object |  | Set upload and download speed limits. See `conditions.speedLimits`. |
| `shareLimits` | object |  | Set ratio and seeding time limits. See `conditions.shareLimits`. |
| `pause` | object |  | Pause matching torrents. See `conditions.pause`. |
| `resume` | object |  | Resume matching torrents. See `conditions.resume`. |
| `recheck` | object |  | Force a recheck of matching torrents. See `conditions.recheck`. |
| `reannounce` | object |  | Force a reannounce of matching torrents. See `conditions.reannounce`. |
| `delete` | object |  | Delete matching torrents. A rule with `delete` has no other action. See `conditions.delete`. |
| `tags` | array of object |  | Tag actions. Each entry manages its own set of tags. See `conditions.tags[]`. |
| `category` | object |  | Set the category of matching torrents. See `conditions.category`. |
| `move` | object |  | Move matching torrents to a different save path. See `conditions.move`. |
| `externalProgram` | object |  | Run an external program for each matching torrent. See `conditions.externalProgram`. |
| `autoManagement` | object |  | Turn automatic torrent management on or off. See `conditions.autoManagement`. |
| `exportToInstance` | object |  | Add matching torrents to a different qBittorrent instance. See `conditions.exportToInstance`. |

### Condition object

A condition is a test or an `AND` or `OR` group of conditions. The `value` of a test is always a JSON string. A number is written as a string, for example "1073741824", and a yes/no value as "true" or "false". `BETWEEN` uses `minValue` and `maxValue` in place of `value`.

| Key | Type | Values | Description |
| --- | --- | --- | --- |
| `field` | condition field |  | The condition field to test. Leave it out on an `AND` or `OR` group. See Condition field names. |
| `operator` | operator |  | An operator that the field allows, or `AND` or `OR` for a group. See Operator names. |
| `groupId` | string | `cross_seed_content_path`, `cross_seed_content_save_path`, `release_item`, `tracker_release_item`, `hardlink_signature` | For `GROUP_SIZE` and `IS_GROUPED`: the group to use. A built-in group ID or the id of a group in `conditions.grouping`. Default: `conditions.grouping.defaultGroupId`. |
| `value` | string |  | The value to compare, always as a JSON string, also for numbers and yes/no values. Not used with `BETWEEN`. |
| `minValue` | number |  | For `BETWEEN`: the lower end of the range, as a JSON number. |
| `maxValue` | number |  | For `BETWEEN`: the upper end of the range, as a JSON number. On `SYSTEM_HOUR`, `SYSTEM_MINUTE`, `SYSTEM_DAY_OF_WEEK` and `SYSTEM_MONTH`, a `minValue` above `maxValue` wraps past the end of the field. |
| `regex` | boolean |  | When `true`, `value` is a regular expression. Applies to string fields. `MATCHES` always uses a regular expression. |
| `negate` | boolean |  | When `true`, the condition matches when the test is false. |
| `conditions` | array of condition |  | For an `AND` or `OR` group: the child conditions. See Condition object. |

### Operator names

| Operator | Meaning |
| --- | --- |
| `AND` | Group. Matches when every child condition matches. |
| `OR` | Group. Matches when at least one child condition matches. |
| `EQUAL` | Equal to `value`. |
| `NOT_EQUAL` | Not equal to `value`. |
| `CONTAINS` | Contains `value`. |
| `NOT_CONTAINS` | Does not contain `value`. |
| `STARTS_WITH` | Starts with `value`. |
| `ENDS_WITH` | Ends with `value`. |
| `MATCHES` | Matches `value` as a regular expression, anywhere in the field. |
| `GREATER_THAN` | Greater than `value`. |
| `GREATER_THAN_OR_EQUAL` | Greater than or equal to `value`. |
| `LESS_THAN` | Less than `value`. |
| `LESS_THAN_OR_EQUAL` | Less than or equal to `value`. |
| `BETWEEN` | From `minValue` to `maxValue`, both included. A range that wraps on a clock field does not include `maxValue`. |
| `EXISTS_IN` | A torrent with exactly this name is in the category `value`. |
| `CONTAINS_IN` | A torrent with a similar name is in the category `value`. Case, accents, and the characters `.`, `_` and `-` do not matter. |
