# Out of scope

One file per rejected concept, not per request. A file records why qui does not do a thing, so that the next request for it gets the same answer without a new debate. Each file has the concept as its title, the reason, and a list of the prior requests.

Only a human writes here, from a local `/triage` session, when a feature request is rejected on scope. The triage workflow reads this directory and closes a new request that matches a recorded concept.

Name the file after the concept in kebab-case: `plugin-system.md`, `graphql-api.md`.
